# Projekt-Franek-Bryndza
⚽ Football Manager
📌 Opis projektu
Football Manager to aplikacja internetowa służąca do zarządzania drużyną piłkarską.

Projekt został stworzony jako projekt na zajęcia. Aplikacja pozwala na zarządzanie zawodnikami, zapisywanie wyników meczów, wyświetlanie statystyk oraz prezentowanie tabeli ligowej.

🎯 Cel projektu
Celem projektu jest stworzenie prostej aplikacji internetowej związanej z piłką nożną, która pozwala użytkownikowi zarządzać podstawowymi informacjami dotyczącymi drużyny.

⚽ Funkcjonalności
👥 Zawodnicy
wyświetlanie listy zawodników,
dodawanie zawodników,
usuwanie zawodników,
wyszukiwanie zawodników,
przypisywanie pozycji,
przypisywanie numerów zawodnikom.
🏟️ Mecze
dodawanie meczów,
wybór przeciwnika,
ustawianie daty spotkania,
wpisywanie wyniku,
automatyczne określanie wyniku jako:
wygrana,
remis,
porażka.
📊 Statystyki
Na stronie głównej wyświetlane są:

liczba zawodników,
liczba rozegranych meczów,
liczba zwycięstw,
liczba strzelonych goli.
🏆 Tabela ligowa
Aplikacja posiada tabelę ligową zawierającą:

pozycję drużyny,
liczbę meczów,
zwycięstwa,
remisy,
porażki,
zdobyte i stracone bramki,
liczbę punktów.

💾 Przechowywanie danych
Dane zawodników i meczów są zapisywane w pamięci przeglądarki za pomocą localStorage.

Dzięki temu po odświeżeniu strony dodane przez użytkownika dane pozostają zapisane.
